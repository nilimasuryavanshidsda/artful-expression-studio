# TVASTRA Canvas

Create a complete modern, premium, responsive static website for **TVASTRA Art Studio**, an offline creative learning studio offering art classes, workshops, and creative activities for **kids, teens, and adults**.

IMPORTANT:

* Do NOT copy the design, layout, branding, text, images, or visual identity of Penkraft or any other reference website.
* The reference website is only for understanding the general business domain and types of services.
* Create a completely original visual identity specifically for TVASTRA Art Studio.
* This is a frontend/static website. No backend, database, authentication, or payment system is required.
* Use realistic placeholder content where actual business information is unavailable.
* Make the website production-quality and interview-ready.

## TECHNOLOGY

Use:

* React
* Vite
* Modern CSS / Tailwind CSS if appropriate
* JavaScript or TypeScript
* Lucide React or another lightweight icon library
* Responsive design for desktop, tablet, and mobile

Do not overcomplicate the project with unnecessary dependencies.
